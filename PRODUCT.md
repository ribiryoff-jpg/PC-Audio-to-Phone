# Product

## Register

product

## Users

Arabic-speaking home users (and family) whose PC has no Bluetooth. They already
pair their Bluetooth earphones with their phone and want the PC's sound there,
over their own Wi-Fi, with zero setup friction. Primary user is non-technical:
big touch targets, numbered steps, no jargon.

## Product Purpose

Bridge PC system audio to a phone over the local network so it plays through
the phone's paired Bluetooth earphones. Two modes: instant low-delay stream
for screen-on use, and a background MP3 stream that survives screen lock.
A per-run 6-digit code plus LAN-only binding keeps it private to the home.

## Brand Personality

Cursor-like restraint: quiet, precise, monochrome, confident. Three words:
minimal, exact, calm.

## Anti-references

- Colorful "silly" UI: rainbow accents, gradients, playful illustration.
- SaaS marketing patterns: hero metrics, eyebrow kickers on every section,
  identical icon-card grids.
- Anything that needs a manual to operate.

## Design Principles

1. Clarity over decoration: every element earns its place or is removed.
2. Monochrome first: black/gray/white carry the UI; green/red appear only as
   functional status, never as decoration.
3. Guide, don't explain: numbered steps and one-line hints beat paragraphs.
4. Trust by default: LAN-only, fresh code each run, no account, no cloud.
5. Multilingual by nature: full Arabic/English/French/Spanish UI with correct
   RTL for Arabic, a first-run picker on desktop and browser detection on web.

## Accessibility & Inclusion

- WCAG AA contrast on body text in both themes.
- Large phone touch targets (≥44px), visible focus states.
- Reduced-motion respected on the web page; no essential info carried by
  color alone (status always pairs icon + text).
